

# Infosys Springboard Internship 7.0 — Batch 4
## Milestone 1: User Authentication Module

### Overview
This project implements a user authentication system using
Streamlit, JWT, Gmail OTP verification, and ngrok.

### Features
- User registration and login
- Input validation and password security
- JWT-based session management
- Password recovery using security questions
- Password recovery using email OTP
- User dashboard and logout
- Separate admin dashboard

### Technology Stack
- Python
- Streamlit
- SQLite
- JWT (PyJWT)
- bcrypt
- Gmail SMTP
- ngrok
- Google Colab

### How to Run
The application is developed and tested in Google Colab.
Setup instructions and execution steps will be documented
after implementation.
